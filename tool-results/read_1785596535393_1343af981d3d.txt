     3→## Project Overview
     4→Building a Next.js "command center" website for Ursa Coffee Roasters (Miraflores, Lima) that presents a researched brand, product, graphic, and marketing plan. Preserves the verified Art Nouveau / bear / roastery identity. No rebrand.
     5→
     6→**Architecture decision:**
     7→- Static HTML dossiers (8 modules + sources) copied to `public/dossier/` as browsable/printable reference (already high-quality, print-friendly, responsive).
     8→- Next.js app at `/` serves as the interactive "command center" with hash-based view routing (stays on the single `/` route per project constraint).
     9→- Includes the interactive Subscription Economics Calculator (core new feature) + 8 extra innovative interactive tools.
    10→
    11→## Tech Stack
    12→- Next.js 16 + TypeScript + Tailwind CSS 4 + shadcn/ui
    13→- Ursa design tokens ported from verified palette (browns, greens, cream, gold)
    14→- Fonts: Cormorant Garamond (display), Inter (body), Oswald (labels)
    15→- Hash-based router for multi-view single-route UX
