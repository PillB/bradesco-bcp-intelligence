# Interactive Tools

## 1. Selection Discipline

Tools are chosen, not defaulted to. Every tool in `TOOL_REGISTRY` must be justified by a specific executive decision it helps make; a tool that only re-displays data with no added decision value is decorative and excluded.

## 2. Candidate Tool Set (select only what is decision-useful per engagement)

Scale Comparator, Metric Normalizer, Product/Service Ecosystem Explorer, Channel Footprint Explorer, Digital Journey Explorer, Technology Capability Heatmap, Technology Radar History, AI/Emerging-Tech Use-Case Explorer, Innovation Funnel (Research→Production Funnel), Partnership Network, Startup Ecosystem Map, Initiative Lifecycle Explorer, Historical Strategy Timeline, Evidence Explorer, Claim Explorer, Contradiction Explorer, Source Freshness Monitor, Comparative SWOT, Similarity/Difference Matrix, Strategic Scenario Builder, Opportunity Prioritizer, Roadmap Tracker.

## 3. Tool Contract

Every interactive tool must: (a) read only from the registries/claim graph, never from hardcoded content; (b) render its underlying evidence status and source for any number shown; (c) be keyboard-operable and screen-reader-labeled; (d) degrade to a static, printable table when interactivity is unavailable (print/export mode).
