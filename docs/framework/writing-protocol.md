# Writing Protocol

## 1. Register

Primary report language and register are set per engagement (e.g., executive Peruvian Spanish for a Peru-based audience), while official names of entities, products, platforms, and programs from other jurisdictions are preserved in their original language rather than translated or localized.

## 2. Sentence-Level Discipline

Writing is precise, direct, evidence-rich, non-promotional, clear, and layered: executive summaries are brief; drilldowns may be deep. Every paragraph must contribute one of: FACT, INTERPRETATION, COMPARISON, IMPLICATION, ACTION, or UNCERTAINTY — a paragraph that does none of these is filler and is cut.

No generic consulting filler. No artificial length for its own sake. No invented numbers. No unsupported superlatives ("leader," "best," "most advanced," "state of the art") unless a specific, cited source makes that exact claim and the claim graph supports it.

## 3. Calibrated Wording

Use explicit epistemic framing tied to the claim's evidence status, e.g.: "[Company] reporta…" (self-reported), "Una fuente independiente corrobora…" (independently corroborated), "La evidencia disponible sugiere…" (inferred/partial), "No existe evidencia pública suficiente para concluir…" (unresolved/unknown). The wording chosen must match the underlying `ClaimRecord.evidence_status` — calibration is not a style choice, it is a data-integrity requirement.

## 4. Standard Section Format (for important sections)

Resumen ejecutivo · Qué sabemos · Evidencia clave · Evolución temporal · Madurez actual · Comparación · Análisis · Explicaciones alternativas · Riesgos y límites · Preguntas abiertas · Implicación estratégica. Each factual/statistical statement exposes `SOURCE, AS-OF, CONFIDENCE` inline or via a linked citation, not just in a bibliography.

## 5. Independence Statement

Every report produced under this protocol carries a visible statement that it is an **independent strategic analysis**, with no implied endorsement by or affiliation with the entities analyzed.
